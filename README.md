# Technology Globalization Foundation (TGF)

**Empowering People. Connecting the World.**

The Technology Globalization Foundation is a nonprofit, being set up in Utah, that brings technology education and digital skills to communities around the world, starting with Cambodia.

## View the website

Open `index.html` in any web browser. No build step is needed.

To publish it for free, turn on **GitHub Pages** for this repository
(Settings → Pages → Deploy from branch → `main` / root). The site will then be live at
`https://<your-username>.github.io/<repository-name>/`.

## Budget

`docs/TGF-Budget-Utah-Nonprofit-Setup.xlsx` has two sheets:

- **Budget**: one-time and yearly costs for setting up TGF as a Utah nonprofit and 501(c)(3), with low, high and planned estimates, status and who handles each item.
- **Expenses**: a log for every expense, with totals by account and a count of expenses missing a receipt.
